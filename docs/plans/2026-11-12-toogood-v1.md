# TooGood To Grow — Plan d'implémentation (étapes 0 à 7)

> **Pour les agents :** SOUS-SKILL REQUIS : superpowers:subagent-driven-development, une **étape de livraison** à la fois, arrêt et validation humaine entre deux étapes. Les étapes utilisent des cases `- [ ]`.

**Objectif :** livrer la PWA « TooGood To Grow » (budget étudiant, 100 % hors ligne, sans backend) selon les étapes 0 à 7 du § 13 de `spec.md`.

**Architecture :** SPA statique en modules ES natifs. `js/domain/` = fonctions pures testées avec `node --test` ; `js/store/` = accès IndexedDB ; `js/views/` = une fonction `render` par écran ; `js/ui/` = composants. Un script de build sans dépendance regroupe les modules dans `dist/` pour tenir le budget de requêtes (voir décision B1).

**Stack :** HTML, CSS, JavaScript (ES2020), IndexedDB, Service Worker, Node 20 (`node:test`, `node:zlib`, `node:crypto`) pour les tests et les outils. Aucune dépendance npm.

**Spec :** `Brief.md` (règles métier, maquette : priorité 1) et `spec.md` (dont § 15 Décisions : priorité 2). Les lire avant chaque tâche.

## Contraintes globales

- Zéro backend, zéro compte, **zéro requête réseau pendant l'usage**, aucune ressource tierce, aucun CDN, aucun tracker.
- Zéro dépendance runtime ; `package.json` sans `dependencies` ni `devDependencies`.
- Polices `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` ; aucune image hors `icons/` ; aucune animation sauf transition ≤ 150 ms sur les boutons, coupée par `prefers-reduced-motion`.
- Couleurs : fond `#FFFFFF`, texte `#1A1A1A`, secondaire `#5F6368`, bordure `#D0D4D9`, accent `#0B6E4F`, alerte fond `#FFF4E5`, alerte texte `#7A4300`.
- Montants en **centimes entiers** ; dates `AAAA-MM-JJ`, mois `AAAA-MM`, locales ; identifiants `crypto.randomUUID()`.
- `js/domain/` : pur, aucun DOM, aucune DB, jamais `new Date()` ; la date du jour (`aujourdhui`) est un paramètre.
- Budget : < 500 Ko transférés (objectif < 150 Ko), ≤ 15 requêtes, Lighthouse a11y ≥ 95, contraste AA, cibles ≥ 44 × 44 px, utilisable à 320 px, Safari iOS 16.
- Interface en français, libellés exacts de la `<maquette>` du brief et de D18.
- Un commit par tâche, message en français au format `type(portée): …`, terminé par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tout texte venant de l'utilisateur (noms) est échappé avant d'être injecté dans le HTML.

## Points de vigilance (non couverts par les tests de la spec)

1. **Montant saisi « à la française »** (« 12,5 », « 1 000 », espaces autour) → accepté ; « 12, » ou « 1e3 » → refusé. *Testé en tâche 1.2.*
2. **Charge modifiée deux fois dans le même mois** → une seule entrée `{ depuis: M+1 }`, la dernière l'emporte. *Testé en tâche 2.1.*
3. **App restée ouverte après minuit** → `aujourdhui` est recalculé à chaque rendu (`ctx.aujourdhui()`), jamais mis en cache au démarrage. *Vérifié en tâche 0.3 (contrat du routeur).*
4. **Nom contenant du HTML** (`<img src=x onerror=alert(1)>`) → affiché comme texte. *Testé en tâche 0.3 (`echapper`).*
5. **Dépense dont la date change de mois** à la modification → `mois` recalculé ; les résumés des deux mois sont recalculés s'ils sont passés. *Testé en tâche 6.1 (`moisImpactes`).*

**Algorithme de `regrouper` (le seul non trivial) :**
- Graphe des imports obtenu par regex. Seules formes acceptées : `import { a, b as c } from './x.js';` et `export function|async function|const|let|class nom`. Toute autre forme (`export default`, `export {…}`, `import x from`, `import()`) fait **échouer** le build avec le nom du fichier.
- Ordre topologique en profondeur d'abord ; un cycle fait échouer le build.
- Chaque module devient `const __mN = (() => { …code… ; return { noms exportés }; })();`, où chaque import est remplacé par `const { a, b: c } = __mK;` et le mot-clé `export` est retiré.
- Sortie : `dist/js/app.js`. Copie de `index.html`, `css/`, `manifest.webmanifest` et `icons/`. `sw.js` est copié en remplaçant `'__VERSION__'` (8 premiers caractères du sha256 du contenu de `dist`) et `'__FICHIERS__'` (liste JSON des fichiers de `dist` sauf `sw.js`, plus `'./'`).

Sinon : `dateDecouvert = ajouterJours(aujourdhui, floor(resteAVivre / moyenne))` et `soldeConseille = soldeQuotidien(resteAVivre, joursRestants)`.
- `depensesDesSeptDerniersJours(depenses, aujourdhui): number` : les 7 jours terminés aujourd'hui inclus.
- `partMensuelle(provision, mois, dejaReserve = 0): number` = `ceil((montantTotal − dejaReserve) / max(1, moisEntre(mois, moisEcheance)))`.
